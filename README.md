# DrugStore向け在庫管理システム

## 概要

- 医薬品卸倉庫の業務を想定して開発した、フリーロケーション対応の在庫管理システムです。
- (現場での)商品の入庫・出庫・在庫照会・入出庫履歴・スタッフ管理を一元化し、現場作業の効率化と入力ミスの削減を目的としています。
- バックエンドはLaravel、フロントエンドはReact（SPA）で構築し、REST APIを介してデータを連携しています。

## 開発背景

医薬品卸倉庫では、商品の種類、ロット、使用期限、数量、保管場所を正確に管理する必要があります。

特に、商品の大きさや入庫数量によっては、1つのロットを1つの棚だけに収められない場合があります。

そのため、本アプリでは商品ごとに棚を固定する方式ではなく、入庫時に空いている棚を選択できる、柔軟な「フリーロケーション方式」を採用しました。

### 解決したい課題
- 入庫・出庫時の数量入力ミスを減らす
- 商品・ロット・棚ごとの在庫状況を可視化する
- 倉庫内の空きスペースを効率的に利用する
- 同じロットの商品を複数の棚に分散して保管する
- 入出庫履歴を残し、在庫変動を追跡できるようにする
- 管理者と現場スタッフの操作範囲を分ける
- フロントエンドとバックエンドを分離したAPI設計を経験する

## アプリの特徴

### フリーロケーション管理

- 従来の固定ロケーション管理とは異なり、入庫時に、任意の棚（フリー・ロケーション）へ商品を配置できる柔軟な在庫管理方式です。
- 同じ商品・同じロットであっても、次のように複数の棚へ分割して保管できます。

例：商品A（130個）を、Aの棚に置けない場合

```text
商品A
└── ロット LOT-20260801
    ├── 棚 A-01：100個
    ├── 棚 A-02：80個
    └── 棚 B-01：50個
```


  
### 本アプリでの実装

- ロット単位で在庫を管理（stock_lots）
- ロットは複数棚に分割可能（stock_lot_locations）
- 棚（locations）ごとに在庫数を保持

これにより、実務に近い「分割入庫・分散管理」を再現しています。
